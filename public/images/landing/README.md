# Previous homepage imagery

These PNGs belong to the previous marketing homepage. The redesigned
`src/pages/LandingPage.tsx` no longer requests them: its product illustrations
are rendered by `src/components/landing/ProductPreview.tsx` using HTML, CSS
and Lucide icons.

The files remain available for existing external references. Do not add them
back to the homepage as full-size banners. The page's scoped styles are in
`src/styles/landing.css`, and its self-hosted fonts and licenses are in
`src/assets/fonts/`.
